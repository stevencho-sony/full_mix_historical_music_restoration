# Ground-truth-validated MOS sensitivity analysis

These aggregate CSVs exclude 11 of 27 listeners whose mean MOS-Quality rating over four clean ground-truth excerpts was below 4.

- Retained listeners: 16
- MOS-Quality ratings: 384
- MOS-Preservation ratings: 256
- Confidence intervals: two-sided 95% Student-t intervals over listener-level condition means

This is explicitly a sensitivity analysis, not an undisclosed replacement for the complete-listener analysis.
