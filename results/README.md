# Results

This directory contains aggregate, anonymous results suitable for public release.

`subjective_mos_gt_mean_at_least_4/` is a sensitivity analysis over 16 listeners whose mean score across four clean ground-truth MOS-Quality items was at least 4. It contains no response IDs or individual listener rows.

The primary all-listener tables and final objective-metric tables will be added after the paper PDF/source is available and its reported values can be checked verbatim.
